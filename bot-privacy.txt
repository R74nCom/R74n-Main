Bots with R74n branding (i.e. R74n Server; Sandboxels Saves) only store limited data that is necessary to serve their basic functions. All user data is stored securely. We comply with the European Union's General Data Protection Regulation (GDPR).

We store content related to moderation tickets sent to or generated by the R74n Server bot. This may include information about infractions, warnings, moderation actions, user metadata, and the contents of messages within the ticket.

We store attachments (particularly shared Sandboxels save files) sent to the #🌐│sandboxels-saves channel.

== Opting Out ==
To opt out of limited message content being tracked, you may run the /opt-out-of-message-content command or send a request to contact@r74n.com.

== Data Deletion ==
To request your limited data be deleted from our servers, send a request to contact@r74n.com, or contact any mod of the R74n Discord server.
